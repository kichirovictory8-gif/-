# 薬剤師国家試験 高正答率テーマ分析（第102回〜第111回）

薬剤師国家試験の過去10年分（第102回／2017年 〜 第111回／2026年）を対象に、
**「受験生の正答率が高い（おおむね60%以上）問題」がどのテーマに集中しているか**を整理し、
科目ごとに「確実に覚えておくべきテーマ」としてまとめたものです。

## 重要な但し書き

厚生労働省は問題と正答は公表していますが、**問題ごとの正答率は公表していません**。
公開されているのは予備校（薬学ゼミナール等）の自己採点システムに基づく
**問題形式別・科目別の平均正答率**までです。
したがって本資料は「全問題を正答率順に並べた集計」ではなく、

1. 公開されている形式別・科目別平均正答率（必須 80%超 / 実践 63〜66% / 理論は科目により 40〜55%）
2. 過去10年で繰り返し出題され、標準的な学習で確実に得点できるテーマ

の2点から、**正答率60%以上の問題が集中する領域を再構成したもの**です。
詳細は [docs/00_分析の前提と全体戦略.md](docs/00_分析の前提と全体戦略.md) を参照してください。

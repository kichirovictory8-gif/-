実験ノート印刷ツール　使い方
==================================================

■ 起動と終了
・「起動.bat」をダブルクリック → 黒い画面が開き、ブラウザが自動で開きます。
・使い終わったら黒い画面を閉じると終了します（ブラウザだけ閉じても動き続けます）。
・ブラウザで開くアドレス：http://127.0.0.1:8765/（自分のPCからしか開けません）
・Python 以外のインストールは不要です。
・ZIPでダウンロードした場合は、必ず「すべて展開」してから使ってください。

■ 置き場所（最初に1回）
・展開先は自分で選んだフォルダでOK。おすすめは C:\jikken-note や
　C:\Users\自分の名前\jikken-note（クラウドで同期されない場所）。
・避ける場所：OneDrive・Dropbox などの同期フォルダ（デスクトップや
　ドキュメントが OneDrive で同期されていることが多い＝雲のマーク）、
　「ダウンロード」フォルダ、共有フォルダ（ネットワークドライブ）。
・他の人と使うときも、フォルダは1台（自分のPC）にだけ置きます。他の人は
　共有モードのアドレスをブラウザで開くだけで、フォルダは要りません。
　（フォルダを配ると、データが人ごとに別々になってしまいます）
・後から移すときは、ツールを終了 → フォルダごと移動 → アイコンを作り直す。

■ デスクトップにアイコンを作る（最初に1回）
・「デスクトップにアイコンを作る.bat」をダブルクリック → 1 か 2 を入力して Enter
　（1＝自分のPCだけ、2＝他のPCからも開ける共有モード）
・デスクトップに青いノートとフラスコの「実験ノート印刷」アイコンができます。
・jikken-note フォルダを移動したら、もう一度この bat を実行してください。

■ プロトコルを登録する（最初に1回）
1. 上のメニュー「プロトコルの管理」→「＋ 新しいプロトコル」
2. 「一覧での名前」と「印刷タイトル」を入力
　 「フォルダ」で 培地／試薬／実験操作 のどれに入れるかを選ぶ。
　 （プロトコルの管理はフォルダごとに表示。行の「フォルダ」欄でもすぐ移せる。
　 　フォルダ名をクリックすると畳める。ホームの選択欄もフォルダごとに分かれる）
3. ブロックを追加して中身を作る（右側に印刷イメージが出ます）
　 見出し／操作手順（↓自動）／文章／試薬と量（自動計算）／表／PCR条件／画像
　 画像ブロックには、画像ファイルを枠にドラッグ＆ドロップしても入れられます。
　 チューブ配置図：本数・チューブの印・サンプル名（上に斜めに表示）・種類（サンプル／
　 　陽性対照／陰性対照／空き＝色分け）・液量を表に書くと図になる。
　 画像は TIFF（.tif）・PNG・JPEG などが使える。TIFF は取り込むときに表示用の形式に
　 　変換され、16ビットの暗い画像は明るさが自動で整う。大きな画像は長い辺2400pxに縮小。
　 泳動画像には「泳動サンプルの試薬」（初期値：DNA 1uL・6×LD 2uL・1/10TE 9uL）が
　 　表示される。量の変更・追加・削除は「この図を編集」の表で。単位がそろえば合計も出る。
　 泳動画像（レーン名）：画像を入れ、切り抜き・明るさをスライダーで調整。レーン数を
　 　入れると等分され、青い線をドラッグして位置を合わせる。「チューブ図から名前を
　 　引き継ぐ」でサンプル名がレーンに入る（M のレーンは飛ばす）。左に目盛り（bp）も可。
　 　記録の入力画面でも、図のすぐ下の「この図を編集」で毎回の名前や画像を直せる。
　 　目盛りの単位（例 (bp)）は、目盛りの上か下を選べる（列の幅は自動で広がる）。
　 　文字の大きさ（%）を、目盛りの数字・レーンの記号・サンプル名・上のラベルごとに変えられる
　 　（目盛りの数字が重なるときは小さくする）。
　 　上のラベル：複数のレーンをまとめて横線＋文字（例 2〜8 レーンに「サンプル名」、「37℃」など）。
　 　段（1〜3）を分けて重ねられる。行の左に「bp」のような見出し（例「温度」「濃度(uL)」）も付けられる。
　 　サンプル名の向きは「自動」（横に入るなら横、長ければ斜め・縦）／横／斜め45°・60°／縦から選べる
　 　（チューブ配置図も同じ）。
　 鋳型DNA・段階希釈：原液の濃度（ug・ng・pg・fg/uL）、1反応に使う液量、希釈倍率、段数、
　 　各チューブの作製量、希釈液（初期値 1/10TE）を入れると、各段の濃度・1反応あたりの
　 　鋳型量（ng・pg を自動で切り替え）・「前の液 ○uL」と「希釈液 ○uL」が表になる。
　 　段ごとに倍率を変えることも、メモ（レーン番号など）を書くこともできる。
　 　段ごとに作製量も変えられる（前のチューブの液が足りないと「不足」と出る）。
　 　原液の濃度を空欄にしておくと、記録の入力画面で毎回入力する黄色の欄になる。
　 操作手順：1行1項目。項目の間に下向き矢印が自動で入る。行頭にスペース（半角・全角）が
　 ある行と「※」で始まる行は補足。矢印は補足（間の空行も）を飛び越えて次の行頭の行まで続く。
　 空行のすぐ後に行頭から始まる行を書くと、そこは矢印なし。
　 補足をまとめてくくる：行を選んで上の「まとめてかっこ」（角の丸いかっこ。「((」と「))」の行で囲まれる）
　 　または「まとめて枠で囲む」（角の丸い枠。「{{」と「}}」の行で囲まれる）。文章ブロックでも使える。
　 まとめて中かっこ＋コメント：行を選んで「まとめて中かっこ」。右側に「}」が付き、その右にコメントが出る
　 　（「>>」と「<< コメント」の行で囲まれる。「<<」の後ろに書いた文字がコメント。コメントは「}」の
　 　とがった所の高さにそろう）。操作の項目をまとめても、補足をまとめてもよい。
　 字下げ：行を選んで Tab（字下げ）／Shift+Tab（戻す）。「字下げの幅 □ 文字にそろえる」で
　 　選んだ行をまとめて同じ幅にできる（0.5 刻み）。
　 操作手順ブロックの「前のブロックから矢印」：自動（前が操作手順のときだけ）／つなぐ（前がどのブロックでも）／
　 　つながない。間に「文章」があれば、補足として矢印がその左を通る。
　 予測変換：英数字を打つと候補が出る（例 v → vortex／vortex & flushing。全角でもOK）。
　 　↑↓で選んで Enter か Tab。単語は「予測変換の単語」ボタンで追加・削除できる（全員で共有）。
4. 毎回変わる所は文字を選んで「可変欄 [[ ]]」ボタン（例：[[サンプル数]]、[[温度=37]]）
　 試薬と量（自動計算）の「計算」は2通り：
　 ・1量 × サンプル数：1サンプルあたりの量にサンプル数を掛ける
　 ・基準量あたりの量 → 作りたい量に換算：「量の基準」（例 1 L、100 mL）あたりの量を
　 　書いておくと、作製量（例 440 mL）に合わせて計算する（例 10g/L → 440mLなら 4.4g）。
　 　単位は uL・mL・L を自動で換算。
　 　試薬の行の「種類」を「作製量と同じ（メスアップ等）」にすると作製量と同じ量（例 stMilliQ 440mL）、
　 　「作製量 × 割合」にすると作製量に割合を掛けた量（例 0.5 → 220mL）になる。
5. 「保存」。編集・複製・削除・並べ替えも「プロトコルの管理」からできます。
　 書式ボタン（選んだ文字に書式）は、下にスクロールしても画面の上に残る。
　 ショートカット：Ctrl+B 太字／Ctrl+U 下線／Ctrl+Alt+H 黄／Ctrl+Alt+R 赤／Ctrl+Alt+V 可変欄／
　 Ctrl+Alt+K 枠囲み／Ctrl+Shift+= 上付き／Ctrl+Shift++ 下付き
　 「プロトコルの管理」では、名前で検索でき、並び順を 自分で決めた順／名前（50音順）／作成日／
　 更新日／最近使った順／よく使う順 から選べる（PCごとに覚える）。
　 「よみがな」は、名前を日本語入力で打つと変換前のひらがなが自動で入る（英語の名前は自分で入力。
　 自分で直すと自動では上書きしない。空にすると自動に戻る）。
　 各ブロックの見出しの「文字」で、そのブロックの文字の大きさ（60〜150%）を変えられる。
　 右の印刷イメージでも、ブロックをドラッグして移動・横に並べることができる。
　 ブロックの右端をドラッグすると幅（画像・泳動画像は大きさ）を変えられる（右端をダブルクリックで元に戻す）。
　 泳動画像ブロックには「ゲル」（小ゲル：1×TAE 20mL・Agarose 0.7%・EtBr 1uL）が出る。
　 　Agarose は % を入れると g を自動計算（% × 1×TAE の mL。初期値 0.7% → 0.14g）。
　 　大ゲルを選ぶと量が2倍になる（記録の入力画面でも切り替えられる）。
　 Gibson：vector と insert の長さ(bp)・濃度(ng/uL)を入れると、分子量（長さ×660）・モル・
　 　必要量(uL、小数第2位まで)を計算する。vector は 50ng 固定、insert は vector と同じモル（比率で変更可）。
　 　insert は「＋ insert を追加」で増やせる。
　 　〈断片（サンプル）〉＝vector＋insert＋stMilliQ、〈断片（Control）〉＝vector＋stMilliQ を、それぞれ
　 　合計 5uL で表示（2つは横に並ぶ）。5uL を超えると「↓ vector と insert をそれぞれ減圧乾燥 ↓」と
　 　〈減圧乾燥後〉の表が出る。乾燥後のそれぞれの量を入れると、stMilliQ で合計 5uL になる量を計算する。
　 　【Master mix】（1倍量 15uL：stMilliQ 残り・5×ISO 4.0uL・dNTPs 1.6uL・T5 exo 0.20uL・
　 　Prime Star 0.20uL）も表示。倍量を入れると量を計算する。

■ 今までの Word・PDF・画像（スクリーンショット）からプロトコルを作る
1. 「プロトコルの管理」→「ファイルを選ぶ」。または、ファイルを画面のどこかに
　 ドラッグ＆ドロップ（複数のファイルをまとめて落としてもOK）。
2. 1つのファイルに複数のプロトコルがあると、「●」で始まる太字・下線の行で
　 分けて一覧が出ます。名前を確認して「チェックしたものを登録」。
　 1件だけのときは編集画面が開くので、確認して「保存」。
3. 見出し（【】〈〉[]）・「↓」の操作手順・PCR条件（98℃、10sec…）・表・画像を
　 自動で見分けます。Word の太字・下線・黄色・赤字・灰色の網かけ（→可変欄）も
　 引き継ぎます。PDF は文字だけ（書式・表の罫線は引き継がれません）。
4. 自動で作るのは「大まかな形」です。取り込んだ後に編集画面で直してください。
・使えるファイル：Word（.docx）、PDF、テキスト（.txt）、画像（PNG・JPEG など）。
　古い .doc は Word で「名前を付けて保存」→ .docx にしてから。
　スキャンした紙のPDF（画像だけのもの）は、ページをスクリーンショット（PNG）にすると取り込める。
・画像（スクリーンショット）は文字を読み取って取り込む（文字認識）。
　「プロトコルの管理」画面で、PNG を「ファイルを選ぶ」か画面にドロップ。
　Windows の「Win + Shift + S」で撮ったスクリーンショットは、そのまま Ctrl+V で貼り付けてもOK。
　文字認識は、ツールを起動している Windows の機能（日本語）を使う。使えないときは
　ブラウザの中で読み取る（少し時間がかかり、精度もやや下がる）。
　数字・単位・記号（℃、×、↓など）は読み間違えることがあるので、必ず確認して直す。
　文字が小さいと読み間違えやすいので、画面を拡大してから撮ると精度が上がる。

■ 注意点・考え方（タグで分類して、実験前に確認）
・上のメニュー「注意点・考え方」→「＋ 新しい注意点」：題名・本文・タグ・★重要を書く。
・検索欄（題名・本文・タグ）とタグのクリックで絞り込み。タグは自由に作れて、
　「タグの整理」で名前の変更・削除（注意点・プロトコル・記録の全部に反映）。
・プロトコル編集画面の「タグ」に同じタグを付けると、そのプロトコルで記録を書くとき
　画面の上に「この実験の注意点」が自動で出る。チェックして「書面の末尾に追加」で、
　【注意点】として文章に入る（プロトコル編集画面からも同じように追加できる）。
・プロトコルの「メモ」欄は「このメモを『注意点・考え方』に移す」で注意点にできる
　（〈 〉【 】● の見出しごとに分けて登録も可）。

■ 記録を書いて印刷する
1. ホームでプロトコルを選び「このプロトコルで書く」
2. 黄色の欄（可変欄）だけ入力（Tabキーで次の欄へ）。
　 試薬表は「×○サンプル分」に数を入れると量が自動で計算されます。
　 ほかの所も直したいときは「全体を編集」タブで書き換えられます。
　 ブロックごとに印刷するかを選べます：各ブロックの左上のチェックを外すと、
　 そのブロックは灰色になり印刷されません（記録ごとに保存。プロトコル編集で外すと、
　 そのプロトコルで書く記録は最初から外れた状態になる）。外したブロックの可変欄は
　 未入力の数に数えません。
3. 「保存して印刷プレビュー」→「印刷する」
　 印刷画面の設定：用紙 A4／倍率 100%（既定）／余白 既定／
　 「ヘッダーとフッター」のチェックを外す
4. 印刷範囲は横17cm×縦27cm（左右2cmずつ空く）。点線の切り取り線つき。
　 印刷プレビューは1ページずつ、実際に印刷されるとおりに表示される。
　 ・印刷プレビューでブロックをドラッグして動かせる。ほかのブロックの右側の空きに落とすと
　 　横に並ぶ（中身の幅の合計が17cmに収まるときだけ。入らないときは赤く表示）。
　 　上半分・下半分に落とすと、その上・下に移る。並べ方はその記録に保存される
　 　（プロトコルは変わらない）。「元に戻す」「並べ方をリセット」もある。
　 　印刷プレビュー・印刷イメージでは、泳動画像（見出し／ゲル／泳動サンプル／画像）、Gibson（見出し／表／
　 　断片（サンプル）／断片（Control）／Master mix）、段階希釈（見出し／表）を部品ごとに動かせる
　 　（編集画面のブロックはそのまま）。「並べ方をリセット」で編集画面の順に戻る。
　 ・印刷の色：印刷プレビューの「色」で カラー／白黒向け を選ぶ。カラーで印刷するときは、
　 　印刷画面の「カラー」を「カラー」にする（白黒になっていると色が付かない）。白黒向けは、
　 　黄色の強調を灰色の網かけ、赤字を黒の太字＋波線で印刷する。
　 ・手順の項目＋補足＋矢印、段落、表、画像、図は途中で切らずに次のページへ送る
　 ・見出しは次の内容と同じページに入る
　 ・少し縮めればページ数が減るときは、85%まで自動で縮める（「○%に縮小」と表示）
　 ・好きな場所で切りたいときは、プロトコル編集（または記録の「全体を編集」）で
　 　「改ページ」ブロックを入れる
　 空欄のままの可変欄は灰色の手書き欄として印刷されます。

■ 過去の記録
・「記録の一覧」から：開く／もう一度印刷／複製して次の実験へ／削除
・検索欄でプロトコル名・日付・中身の文字から探せます。

■ 他の人のPCから開く・編集する（共有モード）
・ツールを入れたPCで「起動（共有）.bat」（またはモード2のアイコン）を起動。
　初回だけ「合言葉」を決めます（半角英数字のみ。かな・漢字は合言葉の欄で入力できない）。
　変えるとき：ツールを止め、data\password.txt をメモ帳で開いて書き換え → 起動し直す。
　Windowsの「アクセスを許可しますか」→「許可」（プライベートネットワーク）。
・黒い画面とホーム画面に出るアドレス（例 http://PC名:8765/）を、
　同じ研究室のネットワークにつながった他のPCのブラウザで開く。
　「合言葉を入力してください」の画面で合言葉を入れて「開く」（そのPCでは30日間入力不要）。
　アドレス欄の「保護されていない通信」の表示は、研究室内だけで使う http 方式のため。
　大事なパスワード（大学のアカウントなど）を合言葉に使い回さないこと。
・他のPCのホーム画面「このPC用のアイコンをダウンロード」→ できた
　「実験ノート印刷.url」をデスクトップに移すと、次からダブルクリックで開けます。
・ツールを入れたPCの電源が入っていて、黒い画面が開いている間だけ使えます。
・2人が同じプロトコル・記録を同時に直して保存すると、後から保存した人に
　「別の人が保存しています」と確認が出ます（相手の変更を消さないため）。
・データは起動したPCの1ファイルだけなので、バックアップもそのPCで行います。
・だれかが保存すると、他の人が開いている画面にも8秒ほどで自動で反映されます
　（自分が直している途中なら上書きせず、上に黄色のお知らせが出ます）。
・ツール本体を新しくしたときは、起動したPCで jikken-note の中身を入れ替えて
　起動し直すだけで全員に反映されます（他のPCには何も入れなくてよい）。
　このとき data フォルダ（記録が入っている）は消さずに残してください。
・大学のネットワークのルールで、自分のPCでのサーバ運用が禁止されていないか
　念のため研究室（または情報システムの窓口）に確認してください。

■ 書式の書き方（詳しくは画面の「書き方のヘルプ」）
　文字を選んでショートカット（もう一度押すと解除）：
　Ctrl+B 太字／Ctrl+U 下線／Ctrl+Alt+H 強調(黄)／Ctrl+Alt+R 注意(赤)／Ctrl+Alt+V 可変欄
　**太字**　==黄色の強調==　!!赤字!!　__下線__　||枠囲み||
　^{上付き}　_{下付き}
　自動：Orc2(1-236) → 1-236 が上付き／His12 → 12 が下付き／
　　　　MgCl2 → 2 が下付き（記録画面のチェックで切り替え）

■ バックアップ（大事）
・データはすべて「data」フォルダの notebook.db という1つのファイルに入っています。
・バックアップ＝このファイルをUSBメモリやクラウドにコピーするだけです。
　（ツールを終了してからコピーすると確実です）
・ホーム画面の「今すぐバックアップ」で「backup」フォルダに日時つきコピーを作れます。
・起動時にも1日1回、自動で backup フォルダにコピーします（最新14回分を保存）。
・元に戻すとき：ツールを終了 → バックアップの .db を data フォルダに置き、
　名前を notebook.db に変える → 起動.bat
・別のPCに移すとき：jikken-note フォルダごとコピーすればそのまま使えます。

■ ツールの更新（新しいバージョンにする）
・データ（プロトコル・記録・注意点・合言葉）は data フォルダにあり、更新では消えない。
1. ホームの「今すぐバックアップ」→ 黒い画面を閉じる
2. 新しい ZIP を別の場所に「すべて展開」→ 中身を全部、今の jikken-note に上書きコピー
3. 起動.bat（共有なら 起動（共有）.bat）で起動し直す
・他の人のPCでは何もしなくてよい。開いている画面に「ツールが新しくなりました」と
　出るので「再読み込み」を押してもらう（閉じていた人は、次に開くと新しくなっている）。
・新しいフォルダに展開してそこから起動しない（data が無いので空に見える）。

■ 困ったとき
・文字が小さい／大きい → 画面右上の「文字 小・中・大・特大」で切り替え（PCごとに覚える。
　印刷の大きさは変わらない）
・ブラウザが開かない → http://127.0.0.1:8765/ を手で開く
・「サーバにつながりません」と出る → 黒い画面が閉じていないか確認し、起動し直す
　（入力した内容は画面に残っているので、起動後にもう一度「保存」）
・他のPCから開けない → 共有モードで起動しているか、同じネットワークか、
　Windowsのファイアウォールで Python が許可されているかを確認
・「Pythonが見つかりません」→ python.org から入れ直し、「Add python.exe to PATH」にチェック
・フォントが明朝にならない → Windows 10（2018年10月以降の更新）以降の
　標準フォント「BIZ UDP明朝 Medium」を使っています。設定 → フォントで確認

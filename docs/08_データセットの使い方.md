# 08. データセットの使い方

必須問題900問（第102〜111回）を、演習・集計の両方に使える形で出力したもの。
**抜粋ではなく全900問**が入っている。

---

## ファイル一覧

| ファイル | 形式 | 用途 |
|---|---|---|
| [`docs/bank/`](bank/) | Markdown 9ファイル | 科目別・テーマ別の問題集。GitHubで読め、正答は折りたたみ |
| `data/hissu_master.csv` | CSV（UTF-8 BOM付き） | **Excelでそのまま開ける。**並べ替え・絞り込み・集計用 |
| `data/hissu_master.tsv` | TSV | スクリプト処理用（カンマを含む問題文でも壊れない） |
| `data/anki_hissu.tsv` | TSV | **Ankiインポート用。**900枚のカードになる |
| `data/hissu_102-111.json` | JSON | 構造化データ。再加工用 |

---

## 正答率の欄について

> ### ⚠️ `正答率` 列は空欄です
>
> **厚生労働省は問題ごとの正答率を公表していません。** 公表されるのは問題・正答・合格基準までです。
> 今回取り込んだ正答表PDFにも含まれていません。
>
> 問題別の正答率が実在するのは、予備校（薬学ゼミナール、メディセレ、e-REC など）が
> 自己採点システムで集計したデータだけですが、それらのサイトは本環境のネットワークポリシーにより
> 参照できません（すべて403）。
>
> **列だけは用意してあります。** 予備校の正答率データ（PDF・CSV・画像いずれでも）を提供いただければ、
> `回` と `問番号` をキーに機械的に結合して、全900問に正答率を埋められます。

代わりに、900問の解析から**実測できる指標**を各問に付けた。以下がその内容。

---

## 列の定義

| 列名 | 内容 |
|---|---|
| `回` | 102〜111 |
| `問番号` | 1〜90 |
| `科目` | 公式正答表の科目欄と照合済み（900問中 不一致0件） |
| `テーマ` | キーワード規則による自動分類 |
| `テーマ出題数_10年` | そのテーマが10年間に出た問題数 |
| `テーマ出題回数_10年` | そのテーマが登場した試験の回数（最大10） |
| `設問形式` | 肯定形 / **否定形**（「誤っているのはどれか」「〜でないのはどれか」型） |
| `計算問題` | ○ = 数値計算を要する |
| `図構造式` | ○ = 図・構造式の読み取りが必要（本文だけでは解けない） |
| `選択肢数` | 通常5。6のものが6問ある |
| `問題文字数` | 設問文の長さ |
| `問題文` / `選択肢1`〜`選択肢5` | PDFから抽出した本文 |
| `正答` | **厚生労働省公表の公式正答** |
| `正答率` | 空欄（上記参照） |
| `類題` | 同一テーマの他年度の問題番号。まとめて解くと定着しやすい |

## 実測指標のサマリー

### 全体（900問）

| 指標 | 該当数 | 割合 |
|---|---:|---:|
| 否定形の設問 | 55問 | 6.1% |
| 計算問題 | 31問 | 3.4% |
| 図・構造式が必要 | 162問 | 18.0% |
| 選択肢が6つ | 6問 | 0.7% |

### 科目別

| 科目 | 問題数 | 否定形 | 計算 | 図・構造式 | 平均文字数 |
|---|---:|---:|---:|---:|---:|
| 物理 | 50 | 1（2%） | 12 | 15（30%） | 72字 |
| 化学 | 50 | 6（12%） | 0 | 32（64%） | 87字 |
| 生物 | 50 | 0（0%） | 0 | 22（44%） | 68字 |
| 衛生 | 100 | 7（7%） | 1 | 14（14%） | 59字 |
| 薬理 | 150 | 3（2%） | 0 | 19（13%） | 50字 |
| 薬剤 | 150 | 4（3%） | 12 | 40（27%） | 61字 |
| 病態・薬物治療 | 150 | 8（5%） | 1 | 9（6%） | 39字 |
| 法規・制度・倫理 | 100 | 16（16%） | 4 | 7（7%） | 54字 |
| 実務 | 100 | 10（10%） | 1 | 4（4%） | 54字 |

**読みどころ**

- **否定形は法規が突出（16%）**、次いで実務（10%）、化学（12%）。
  法規は「正しいのはどれか」と「誤っているのはどれか」が混在するため、設問の読み違えが致命傷になる。
- **計算問題は物理と薬剤に集中**（各12問）。他科目はほぼ出ない。
- **図・構造式が必要な問題は化学が64%**。名称の暗記だけでは通用しない。
  一方で**実務は4%、病態は6%**と、ほぼ文章題。
- 生物には否定形が10年間で1問もない。

## Excelでの使い方

`data/hissu_master.csv` はUTF-8 BOM付きなので、ダブルクリックでそのままExcelが開く。

おすすめの使い方:

1. **オートフィルタ**をかけて、`科目`＋`テーマ`で絞り込む → 同テーマを連続で解く
2. `設問形式` を「否定形」で絞る → ひっかかりやすい55問だけを潰す
3. `図構造式` が空欄のものだけ絞る → 移動中でも解ける問題だけ抽出
4. 右端の `正答率` 列に自分の正誤や予備校データを入力して、ピボットテーブルで集計

## Ankiへの取り込み手順

1. Ankiを開き、**ファイル → 読み込む** で `data/anki_hissu.tsv` を選択
2. フィールドの区切りは**タブ**、「HTMLとして扱う」に**チェック**（ファイル先頭で指定済みなので通常は自動）
3. フィールドの対応：1列目 → 表面、2列目 → 裏面、3列目 → タグ

付与されるタグ:

- `薬剤師国家試験` `必須問題`
- `科目::薬理` のような階層タグ（Ankiのサイドバーで科目別に展開できる）
- `テーマ::自律神経作用薬` のような階層タグ
- `第104回` のような年度タグ
- `flag::否定形` `flag::計算` `flag::図`（該当問題のみ）

タグで絞り込めば「薬理の自律神経だけ」「否定形だけ」といった演習ができる。

## 注意

- 問題文はPDFから機械的に抽出したもの。上付き・下付き文字は平坦化され、一部の記号は `□` になっている。
  正確な表記は原文PDFを参照すること。
- テーマ分類は自動判定であり、境界的な問題の帰属には揺れがある（未分類は900問中36問＝4%）。
- 正答は公式値だが、抽出・転記の過程を経ているため、重要な判断には原典を確認すること。

# 05. 必須問題 10年分の出題数（実測）

第102回（2017年）〜第111回（2026年）の**必須問題PDF 10冊・計900問を全文解析した実測値**。
これまでの資料で使っていた ◎○△ の頻度推定は、以下の実測データに置き換える。

## 集計方法

1. 厚生労働省公表の各回「必須問題」PDFからテキストを抽出（pdfminer.six）
2. 問番号で900問に分割（**900/900問を欠損なく取得**）
3. 問番号から科目を判定（問1-5物理／6-10化学／11-15生物／16-25衛生／26-40薬理／41-55薬剤／56-70病態／71-80法規／81-90実務）
4. キーワード規則でテーマを割り当て（未分類は900問中36問＝4%）

**注意**：テーマの割り当ては自動分類であり、境界的な問題の帰属には揺れがある。
出題数は傾向を掴むための概数として読むこと。

# 推定が外れていた点（重要）

実測して、以前の ◎○△ 推定と食い違った箇所がある。**以下は推定のほうが誤り**だった。

| 科目 | 推定 | 実測 | コメント |
|---|---|---|---|
| 物理・放射化学 | ◎（ほぼ毎年1-2問） | **50問中4問（3/10回）** | 過大評価。必須では毎年は出ていない |
| 物理・分析の基礎／単位／バリデーション | 記載なし | **50問中10問で最多** | 単位換算・精度・器具・バリデーションが実は最頻出 |
| 生物・代謝経路 | ◎ | **50問中2問** | 大幅な過大評価。必須では稀 |
| 生物・人体の構造と機能 | ◎ | **50問中13問で最多** | 解剖生理・生化学の基礎が中心 |
| 衛生・疫学 | ○ | **100問中4問** | 必須では少ない（理論問題に多い） |
| 薬剤・製剤材料の物性 | ○ | **150問中35問で最多** | 動態より製剤物性のほうが多い |
| 薬理・自律神経作用薬 | ◎ | **150問中38問（10/10回）** | 推定どおり。必須薬理の4分の1 |
| 病態・副作用・薬剤性疾患 | ◎ | **150問中18問で最多** | 推定どおり |

- 衛生：環境衛生、化学物質の毒性・解毒
- 薬理：自律神経作用薬

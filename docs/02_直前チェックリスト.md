## 物理
- [ ] α／β⁻／β⁺・EC 壊変での質量数・原子番号の変化
- [ ] 有効半減期 1/Te = 1/Tp + 1/Tb
- [ ] ⁹⁹ᵐTc・¹³¹I・¹²³I-MIBG・¹⁸F-FDG・²⁰¹Tl の用途
- [ ] Henderson–Hasselbalch 式と緩衝能最大の条件（pH = pKa）
- [ ] 1次反応の半減期は初濃度に依存しない
- [ ] Lambert–Beer 則、IR の特性吸収、NMR の積分比＝プロトン数
- [ ] MS の Cl（3:1）・Br（1:1）同位体パターン
- [ ] 逆相クロマト＝極性が低いほど後に溶出
- [ ] ΔG = ΔH − TΔS、ΔG° = −RT ln K

## 化学
- [ ] R/S 表示と CIP 則、立体異性体の最大数 2ⁿ
- [ ] 酸性度：スルホン酸 > カルボン酸 > フェノール > アルコール
- [ ] o,p配向性（−OH、−NH₂、−R、ハロゲン）と m配向性（−NO₂、−COOH、−CN）
- [ ] 甘草＝グリチルリチン＝偽アルドステロン症
- [ ] 麻黄＝エフェドリン、大黄＝センノシド、黄連＝ベルベリン
- [ ] 小柴胡湯＝間質性肺炎（インターフェロン併用禁忌）
- [ ] 第I相（酸化・還元・加水分解）と第II相（各種抱合）
- [ ] アセトアミノフェン → NAPQI → N-アセチルシステイン

## 生物
- [ ] 解糖系の律速＝ホスホフルクトキナーゼ、TCAは ミトコンドリアマトリックス
- [ ] ビタミンと補酵素・欠乏症の対応表（B₁/B₆/B₁₂/葉酸/K）
- [ ] イソニアジド → ビタミンB₆欠乏 → 末梢神経障害
- [ ] 抗体クラスの特徴（IgG胎盤通過／IgM五量体／IgA分泌型／IgE即時型）
- [ ] アレルギーI〜IV型の機序と代表疾患
- [ ] MHCクラスI＝CD8⁺T、クラスII＝CD4⁺T
- [ ] 競合阻害（Km↑Vmax不変）／非競合阻害（Km不変Vmax↓）
- [ ] ビタミンK依存性凝固因子 II・VII・IX・X

## 衛生
- [ ] 食中毒：感染型／毒素型／ウイルス／自然毒の代表と特徴
- [ ] 黄色ブドウ球菌の毒素は耐熱性、ノロは次亜塩素酸（アルコール無効）
- [ ] コホート→相対危険度、症例対照→オッズ比
- [ ] 感度・特異度・陽性的中率の2×2表
- [ ] 感染症法1〜5類の代表疾患、予防接種法A類/B類
- [ ] 死因順位：悪性新生物 ＞ 心疾患 ＞ 老衰 ＞ 脳血管疾患
- [ ] 解毒薬一覧（有機リン＝PAM＋アトロピン、水銀＝BAL、鉄＝デフェロキサミン…）
- [ ] 代謝的活性化（ベンゾ[a]ピレン、アフラトキシン、ニトロソアミン）
- [ ] 上水＝塩素消毒とトリハロメタン、下水＝活性汚泥法
- [ ] 油脂の変質指標（酸価・過酸化物価・ヨウ素価）

## 薬理
- [ ] 受容体サブタイプ（α₁/α₂/β₁/β₂/β₃、M₁/M₂/M₃）と効果器
- [ ] 抗コリン薬の禁忌＝閉塞隅角緑内障・前立腺肥大
- [ ] ACE阻害薬＝空咳・血管浮腫・妊婦禁忌
- [ ] Vaughan Williams 分類 Ia/Ib/Ic/II/III/IV の代表薬
- [ ] 硝酸薬とPDE5阻害薬は併用禁忌
- [ ] ワルファリン＝ビタミンK・納豆・PT-INR、DOACとの違い
- [ ] 定型抗精神病薬＝D₂遮断＝錐体外路症状・高プロラクチン血症
- [ ] SSRI＝セロトニン症候群、抗精神病薬＝悪性症候群
- [ ] ビスホスホネート＝起床時・水・30分臥位禁止・顎骨壊死
- [ ] 抗結核薬 INH/RFP/EB/PZA/SM の副作用
- [ ] シクロホスファミド＝出血性膀胱炎＝メスナ
- [ ] シスプラチン＝腎毒性＋強い催吐性、イリノテカン＝下痢

## 薬剤
- [ ] CL = ke×Vd = Dose/AUC、Css = k₀/CL
- [ ] 定常状態到達は半減期の4〜5倍
- [ ] CYP阻害（マクロライド、アゾール、グレープフルーツ）／誘導（リファンピシン、カルバマゼピン、セントジョーンズワート、喫煙）
- [ ] CYP2D6（コデイン→モルヒネ）、CYP2C19（クロピドグレル）の多型
- [ ] キレートによる吸収低下（Ca/Mg/Al/Fe × テトラサイクリン・キノロン）
- [ ] pH分配仮説と尿pHによる排泄変化
- [ ] TDM対象薬とトラフ採血のタイミング
- [ ] 腸溶性・徐放性製剤は粉砕不可
- [ ] Noyes–Whitney 式、Arrhenius による有効期間予測
- [ ] 乳剤のHLB、クリーミングと合一の違い

## 病態・薬物治療
- [ ] 糖尿病診断基準（HbA1c 6.5%、空腹時126、OGTT 200）
- [ ] CKDステージとeGFR、腎機能による用量調節
- [ ] CK上昇＋褐色尿＝横紋筋融解症
- [ ] 高熱＋筋強剛＋CK上昇＝悪性症候群 → ダントロレン
- [ ] 間質性肺炎を起こす薬（小柴胡湯、MTX、EGFR-TKI、アミオダロン）
- [ ] SJS/TEN の原因薬（カルバマゼピン、アロプリノール、ST合剤）
- [ ] アナフィラキシー＝アドレナリン0.3 mg 大腿前外側に筋注
- [ ] 心房細動＋CHADS₂スコア → 抗凝固療法
- [ ] H. pylori 除菌レジメン（一次・二次）
- [ ] WHO方式がん疼痛治療とレスキュー、オピオイド換算
- [ ] 妊婦禁忌薬（ワルファリン、ACE阻害薬/ARB、バルプロ酸、テトラサイクリン、レチノイド）
- [ ] 小児のアスピリン → Reye症候群

## 法規・制度・倫理
- [ ] 薬剤師法24条 疑義照会、25条の2 情報提供・指導義務
- [ ] 処方箋の保存3年、調剤録3年、麻薬帳簿2年
- [ ] 毒薬＝黒地に白枠白字「毒」／劇薬＝白地に赤枠赤字「劇」
- [ ] 要指導医薬品・第1類〜第3類の販売者と情報提供義務
- [ ] 麻薬は鍵をかけた堅固な設備、廃棄は届出＋職員立会い
- [ ] 調剤済麻薬の廃棄は30日以内に届出、事故届は速やかに
- [ ] 医療計画＝5疾病6事業及び在宅医療（新興感染症を含む）
- [ ] 介護保険：1号65歳以上／2号40〜64歳（特定疾病）
- [ ] 副作用被害救済制度の対象外（法定予防接種、抗がん剤等、不適正使用）
- [ ] 薬害の原因薬（サリドマイド、キノホルム、非加熱血液製剤、ソリブジン）

# 01. 科目別「覚えておくべきテーマ」

第102回（2017年）〜第111回（2026年）の10年分で、**正答率60%以上の帯に入る問題が集中するテーマ**を科目別に整理した。
各テーマの ★ は出題頻度と正答率の高さの目安。

- ★★★ … ほぼ毎年出題、正答率70〜90%。落とすと差がつく
- ★★ … 2〜3年に1回、正答率60〜75%。標準問題の中心
- ★ … 出題は散発的だが、出たときは正答率が高い

# 物理（必須5 / 理論10 / 実践5 ＝ 年20問前後）

理論の平均正答率は40%前後まで落ちるが、**必須と実践の定番は70%超**。以下に絞って固める。

## ★★★ 放射化学
10年間で最も安定した高正答率テーマ。ほぼ毎年出題され、必須では正答率80%を超える。

- 壊変形式：α壊変（質量数−4、原子番号−2）、β⁻壊変（原子番号+1）、β⁺壊変・EC（原子番号−1）、γ遷移
- 半減期計算：`A = A₀(1/2)^(t/T)`。物理的半減期・生物学的半減期・**有効半減期**（1/Te = 1/Tp + 1/Tb）
- 放射性医薬品と用途
  - ⁹⁹ᵐTc：骨シンチ、心筋、脳血流（γ線、T=6時間）
  - ¹³¹I：甲状腺（治療にも使う β⁻）、¹²³I：甲状腺シンチ、¹²³I-MIBG：褐色細胞腫・心筋交感神経
  - ¹⁸F-FDG：PET（腫瘍の糖代謝）、β⁺壊変
  - ²⁰¹Tl：心筋血流、⁶⁷Ga：炎症・腫瘍
- 放射線の単位：Bq（放射能）、Gy（吸収線量）、Sv（等価・実効線量）

## ★★★ 酸塩基平衡・緩衝液
- Henderson–Hasselbalch 式 `pH = pKa + log([A⁻]/[HA])`
- 弱酸・弱塩基のpH計算、緩衝能が最大になる条件（pH = pKa）
- pH分配仮説（薬剤の吸収と連結して実践で頻出）

## ★★ 反応速度論
- 0次・1次・2次反応の速度式と濃度−時間プロット（1次は片対数で直線）
- 1次反応の半減期 `t₁/₂ = 0.693/k`（**濃度に依存しない**）
- Arrhenius 式と活性化エネルギー、温度10℃上昇で速度約2〜3倍

## ★★ 熱力学
- `ΔG = ΔH − TΔS`、ΔG<0 で自発的
- `ΔG° = −RT ln K`
- エンタルピー／エントロピー変化の符号の意味（疎水性相互作用はΔS駆動）

## ★★ 機器分析（必須の定番）
- **紫外可視吸光度**：Lambert–Beer 則 `A = εcl`、吸光度と透過率
- **IR**：特性吸収（O–H 3300, N–H 3400, C=O 1700, C≡N 2250 cm⁻¹）
- **¹H-NMR**：化学シフト（TMS基準）、**積分比＝プロトン数**、スピン結合とn+1則
- **MS**：分子イオンピーク、Cl（M:M+2 = 3:1）・Br（1:1）の同位体パターン
- 蛍光光度法、原子吸光、旋光度と比旋光度

## ★★ クロマトグラフィー
- 順相／逆相の区別（逆相＝ODS、極性が低い成分ほど後から溶出）
- 理論段数 N、分離度 Rs、保持時間・保持係数 k
- TLC の Rf 値、GC の検出器（FID、ECD）

## ★ 日本薬局方・一般試験法
- 定量法：中和滴定、**非水滴定**（弱塩基性医薬品）、キレート滴定（EDTA）、酸化還元滴定（ヨウ素、過マンガン酸）
- 確認試験・純度試験・崩壊試験・溶出試験の目的

## ★ 溶液・界面
- 束一的性質（浸透圧、凝固点降下）、等張化計算
- 界面活性剤の分類とHLB、**臨界ミセル濃度（CMC）**、可溶化

# 化学（必須5 / 理論10 / 実践5 ＝ 年20問前後）

理論の正答率は約54%（第110回）で基礎3科目の中では比較的高い。**生薬・天然物と立体化学が確実な得点源**。

## ★★★ 生薬・漢方（最も正答率が高い化学分野）
一問一答で完結するため、毎年ほぼ確実に正答率70%超。

- 基原植物 − 薬用部位 − 主成分 − 薬効 の4点セットで覚える
  - 麻黄（マオウ）− エフェドリン − 気管支拡張
  - 甘草（カンゾウ）− グリチルリチン − **偽アルドステロン症**（低K血症、浮腫、血圧上昇）
  - 大黄（ダイオウ）− センノシド − 瀉下
  - 黄連・黄柏 − ベルベリン − 止瀉、苦味健胃
  - 芍薬 − ペオニフロリン、人参 − ギンセノシド、桂皮 − シンナムアルデヒド
  - 附子 − アコニチン（毒性）、センナ − センノシド
- 漢方処方と副作用（実践で頻出）
  - **小柴胡湯 − 間質性肺炎**（インターフェロン併用禁忌）
  - **甘草含有処方 − 偽アルドステロン症**（芍薬甘草湯、葛根湯、小青竜湯…）
  - **麻黄含有処方 − 動悸・不眠・血圧上昇**（高血圧、心疾患に注意）
  - 大建中湯（術後イレウス）、抑肝散（認知症BPSD）、六君子湯（食欲不振）、牛車腎気丸（しびれ）
- 成分の化学分類：アルカロイド、テルペノイド、フラボノイド、配糖体、タンニン

## ★★★ 立体化学
- **キラル中心の判定と R/S 表示**（CIP則）
- エナンチオマー／ジアステレオマー／メソ体の区別、光学活性の有無
- 立体異性体の最大数 2ⁿ
- 医薬品の光学異性体と活性差（L-DOPA、S-ワルファリン、サリドマイド）

## ★★ 官能基と酸性度・塩基性度
- 酸性度の序列：スルホン酸 > カルボン酸 > フェノール > アルコール
- 電子求引基（−NO₂、−CF₃、ハロゲン）で酸性度↑、電子供与基で↓
- アミンの塩基性（脂肪族アミン > アンモニア > 芳香族アミン > アミド）
- 医薬品の酸塩基性と製剤・吸収・排泄への影響

## ★★ 有機反応の基本
- SN1/SN2、E1/E2 の反応条件と立体化学（SN2は立体反転）
- 芳香族求電子置換の配向性
  - **o,p配向（活性化）**：−OH、−OR、−NH₂、−NHCOR、−R
  - **o,p配向（不活性化）**：−F、−Cl、−Br、−I
  - **m配向（不活性化）**：−NO₂、−COOH、−CHO、−SO₃H、−CN、−CF₃
- カルボニルへの求核付加、エステルの加水分解、アミド結合の形成

## ★★ 医薬品の構造と分類（実践で高正答率）
- β-ラクタム系：ペニシリン／セフェム／カルバペネム／モノバクタムの骨格の違い
- キノロン系（キレート形成による吸収低下）、テトラサイクリン系（Ca・Mg・Alとキレート）
- ステロイド骨格（シクロペンタノペルヒドロフェナントレン）と副腎皮質ホルモン／性ホルモン
- サルファ剤とp-アミノ安息香酸の構造類似（拮抗阻害）
- プロドラッグの構造的仕掛け（エステル化による吸収改善：エナラプリル、ロキソプロフェン）

## ★ 薬物代謝の化学
- 第I相：酸化（CYP）、還元、加水分解 → 官能基の導入
- 第II相：グルクロン酸抱合、硫酸抱合、グルタチオン抱合、アセチル化、メチル化
- 代謝的活性化（アセトアミノフェン → NAPQI → グルタチオン枯渇 → 肝障害、解毒はN-アセチルシステイン）

# 薬理（必須15 / 理論15 / 実践10 ＝ 年40問）

必須の正答率は80%超。**「薬 → 受容体・酵素 → 作用 → 副作用」の4点セット**が問われる形が10年間一貫。

## ★★★ 自律神経作用薬（毎年必出・最優先）
- 受容体サブタイプと効果器の対応
  - α₁：血管収縮、瞳孔散大（散瞳）、前立腺・尿道収縮
  - α₂：シナプス前抑制（中枢性降圧）

# 薬剤（必須15 / 理論15 / 実践10 ＝ 年40問）

計算問題の比重が大きく、**第111回では理論の半分以上が計算・グラフ**。
ただし**必須の基本計算と相互作用は正答率が高い**。

## ★★★ 薬物動態の基本計算
- 1-コンパートメントモデル：`C = C₀·e^(−ke·t)`、`t₁/₂ = 0.693/ke`
- **Vd = X/C**、**CL = ke × Vd**、**CL = Dose/AUC**
- バイオアベイラビリティ `F = (AUC_po × Dose_iv)/(AUC_iv × Dose_po)`
- 点滴静注の定常状態 **Css = k₀/CL**、定常状態到達は半減期の4〜5倍
- 繰り返し投与の蓄積率、負荷投与量 `LD = Css × Vd/F`
- 腎機能低下時の投与設計（**Giusti–Hayton 法**、Ccr補正）

## ★★★ 薬物相互作用（実践で最頻出・正答率高）
- **CYP阻害**：マクロライド（クラリスロマイシン）、アゾール系抗真菌薬、**グレープフルーツジュース（CYP3A4・腸管）**、シメチジン → 併用薬の血中濃度↑
- **CYP誘導**：**リファンピシン、カルバマゼピン、フェニトイン、フェノバルビタール、セイヨウオトギリソウ（セントジョーンズワート）、喫煙（CYP1A2）** → 併用薬の血中濃度↓
- 主要CYP分子種と基質：3A4（最多）、2D6（コデイン → モルヒネ、多型）、2C9（ワルファリン）、2C19（クロピドグレル、PPI、多型）、1A2（テオフィリン）
- **P-糖タンパク質（P-gp）**：ジゴキシン、ベラパミルによる阻害
- キレート・吸着による吸収低下：**Ca・Mg・Al・Fe とテトラサイクリン／ニューキノロン／ビスホスホネート**、コレスチラミン
- 尿pHによる排泄変化（酸性薬物は尿アルカリ化で排泄↑＝**サリチル酸中毒に炭酸水素ナトリウム**）

## ★★★ 吸収・分布・代謝・排泄
- 膜透過：単純拡散（**pH分配仮説**：非イオン形が透過）、担体介在輸送（PEPT1、OATP、OCT、MRP、BCRP）
- **初回通過効果**を回避する投与経路（舌下、坐剤下部、経皮、注射）
- 血漿タンパク結合：アルブミン（酸性薬物）、α₁酸性糖タンパク（塩基性薬物）、**遊離形のみが薬効・分布・消失に関与**
- 血液脳関門、胎盤通過、乳汁移行
- 腎排泄：**糸球体ろ過（遊離形のみ）＋尿細管分泌（能動）− 再吸収**、腎クリアランスとGFR（イヌリン）の比較

# 薬剤師国試 フラッシュカード（PC用・オフライン）

2028年2月の薬剤師国家試験に向けた、**間隔反復のフラッシュカード**アプリです。
自分のPCの中だけで動きます（インターネット不要・外部サービスなし）。Anki と併用する前提です。

- カード：科目（9区分）・系統・単元（任意）・表面・裏面
- 穴埋め：表面に `{{c1::語句}}` または `{{c1::語句::ヒント}}`
- 復習：1 → 3 → 7 → 14 → 30 → 60 → 120日 の固定間隔＋○△✖の自己評価
- データ：**1つのファイル（SQLite）** に保存。コピーするだけでバックアップできます

---

## はじめての準備（1回だけ）

このアプリを動かすには **Python 3.9 以上**（無料）が必要です。

1. ブラウザで <https://www.python.org/downloads/> を開き、黄色い **「Download Python 3.x.x」** を押してインストーラーを保存する
2. インストーラーを開き、最初の画面の下にある **「Add python.exe to PATH」にチェック** を入れて **「Install Now」** を押す
3. 「Setup was successful」と出たら閉じる

> 追加でインストールするライブラリはありません（Python の標準機能だけで動きます）。

## 起動と終了

- **起動**：`app` フォルダの **`start.bat` をダブルクリック**
  黒い画面（サーバー）が開き、少しするとブラウザでアプリが開きます。
  - ブラウザが開かないときは、アドレス欄に `http://127.0.0.1:8765/` と入力してください
  - デスクトップから起動したい場合は、`start.bat` を右クリック →「ショートカットの作成」で作ったショートカットをデスクトップに置きます
  - 2回目の起動では、すでに動いているアプリをブラウザで開き直すだけです
- **終了**：黒い画面を閉じる（または黒い画面で `Ctrl+C`）。
  評価や追加は1件ごとにすぐファイルに保存されるので、いつ閉じても大丈夫です。

コマンドで起動する場合（`app` フォルダで）：

```bash
py -3 server.py
```

## iPad から使う（同じ Wi-Fi の中だけ）

PC でアプリを動かしたまま、iPad の Safari から PC のアプリを開いて使えます。
データは PC の1つのファイルのままなので、**PC と iPad のどちらで学習しても同じ履歴**に記録されます。

**使い方**

1. PC で **`start_ipad.bat` をダブルクリック**して起動する（いつもの `start.bat` の代わり）
   - すでに `start.bat` で起動している場合は、その黒い画面を閉じてから起動してください
2. 黒い画面に **iPad で開くアドレス**（例：`http://192.168.1.23:8765/`）と **6桁のパスコード**が表示されます
   （PC で開いたアプリの「データ」画面にも表示されます）
3. iPad を **PC と同じ Wi-Fi** につなぎ、Safari のアドレス欄にそのアドレスを入力する
4. パスコードを入力する。**一度入力すれば、その iPad では次回から入力不要**です

**初回だけ：Windows のファイアウォール**

初めて `start_ipad.bat` で起動したとき、「Windows セキュリティの重要な警告」が出ます。
**「プライベート ネットワーク」にチェック**を入れて **「アクセスを許可する」** を押してください。
（ここで許可しないと iPad から開けません。後から許可するには「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」で Python にチェックを入れます）

**iPad での操作**

- カード（またはボタン）をタップすると答えが表示され、○ / △ / ✖ のボタンをタップして評価します
- Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で開けます。
  ホーム画面から開いた場合は、Safari とは別扱いになるため、最初の1回だけもう一度パスコードを入力します

**知っておくこと**

- iPad で使っている間は、PC の電源を入れたまま、黒い画面を開いたままにしてください（スリープすると iPad から開けなくなります）
- 外出先など、PC と違うネットワークからは使えません
- PC の IP アドレスは、ルーターの再起動などで変わることがあります。開けなくなったら、黒い画面に表示されるアドレスを確認してください（アドレスが変わったときは、パスコードの入力ももう一度必要です）
- パスコードを変えたいとき（iPad をなくしたときなど）は、**PC で**「データ」画面の「パスコードを変更する」を押します。登録済みの iPad はすべて入力し直しになります
- パスコードを5回続けて間違えると、その iPad からは10分間入力できなくなります
- パスコードと登録済み端末の情報は `ドキュメント\yakushi-flash\settings.json` に保存されます
- PC からは今までどおり `http://127.0.0.1:8765/` で開け、パスコードは不要です
- 同じ Wi-Fi に家族など他の人がいても、パスコードを知らなければ開けません。ただし通信は暗号化していないので、カフェやホテルなどの**公共の Wi-Fi では `start_ipad.bat` を使わないでください**

## 画面と使い方

| 画面 | できること |
|---|---|
| 今日 | 期日の枚数（期限切れを含む）、今日の復習数、連続日数、段階ごとの枚数、直近14日の実績、今後7日の予定。「学習を始める」は全科目または科目ごと |
| 学習 | 期日の古い順に出題。✖ にしたカードは、その日のセッションの最後に1回だけ再確認として出ます |
| 追加 | **1枚ずつ**：`Ctrl+Enter` で保存すると、科目と系統はそのまま残って次のカードを続けて入力できます。**まとめて**：1行1枚（`表面[Tab]裏面`）を貼り付け、プレビューを確認して追加 |
| カード一覧 | 検索（表面・裏面・系統）、科目・理解度・期日での絞り込み、並べ替え。行をクリックすると編集・削除・学習状況のリセット・評価の履歴 |
| 科目別・系統別 | 枚数、○/△/✖/未学習の数、平均周回数、定着率。科目の行をクリックすると系統別が開きます |
| 苦手リスト | 直近14日（7日・30日にも切替可）で ✖ が2回以上のカード（1回以上・3回以上にも切替可）と、✖ の多い系統 |
| データ | データファイルの場所、バックアップの作成、JSON の書き出し・取り込み |

### キーボード操作

| 場所 | キー | 動作 |
|---|---|---|
| 学習 | `Space`（または `Enter`） | 答えを表示 |
| 学習 | `1` / `2` / `3` | ○ / △ / ✖ |
| 学習 | `E` | 表示中のカードを編集 |
| 追加・編集 | `Ctrl+Enter` | 保存（追加画面では保存して次のカードへ） |
| 追加・編集 | 語句を選んで `Alt+C` | 選んだ語句を `{{c1::…}}` で囲む（追加画面では「選んだ語句を穴埋めにする」ボタンでも可） |
| まとめて追加 | `Tab` | 入力欄に Tab を入れる（表面と裏面の区切り） |
| カード一覧 | `/` | 検索欄へ移動 |
| 今日 | `Enter` | 学習を始める |

### 穴埋め

- `{{c1::語句}}` は `[…]`、`{{c1::語句::ヒント}}` は `[ヒント]` として隠れます
- 1枚の中に `c1`・`c2` … が複数あっても、**全部まとめて隠した1枚**として出ます
- 答えを表示すると、語句が色付きで現れ、その下に裏面が表示されます。穴埋めカードは裏面を空にしてもかまいません

## 復習のルール

| 評価 | 段階 | 次の期日 |
|---|---|---|
| ○ | 1つ進む（最大で120日） | 評価した日 ＋ 進んだ段階の間隔 |
| △ | そのまま | 評価した日 ＋ 今の段階の間隔（新規カードなら翌日） |
| ✖ | 新規に戻る | 翌日。その日のセッションの最後に1回だけ再確認として出る |

- 段階は 新規 → 1日 → 3日 → 7日 → 14日 → 30日 → 60日 → 120日
- 新しく追加したカードは、追加した日が期日です（1日の上限はありません）
- 期限切れのカードも「今日の期日」に含まれ、**期日の古い順**に出ます。次の期日は、元の期日ではなく評価した日から数えます
- 再確認での評価は履歴に残りますが、間隔や集計には影響しません
- **1日の区切りは午前2時**です（0:00〜1:59 の学習や追加は前日の扱い）
- すべての評価は日時つきで履歴に残ります（カード一覧 → カードをクリック）

## 集計の定義

| 項目 | 定義 |
|---|---|
| 今日の復習数 | 今日の評価の回数（再確認を除く） |
| 連続日数 | 1日1回以上評価した日が何日続いているか。今日まだ評価していなければ、昨日までの日数 |
| ○ / △ / ✖ | 各カードの**最後の評価**（再確認を除く）で分類 |
| 未学習 | 一度も評価していないカード |
| 平均周回数 | 評価の回数（再確認を除く）÷ 枚数 |
| 定着率 | 間隔が30日以上（段階5以上）のカード ÷ その科目・系統の全カード（未学習を含む） |
| 苦手リスト | 期間内の ✖ の回数（再確認の ✖ は数えない） |

**学習状況のリセット**をしたカードは、新規に戻り、今日が期日になります。それまでの評価は履歴として残りますが、上の集計には数えません。
**削除**したカードは、評価の履歴も一緒に消えます。

## データファイルの場所

```
ドキュメント\yakushi-flash\flashcards.db
```

（例：`C:\Users\<ユーザー名>\Documents\yakushi-flash\flashcards.db`。ドキュメントを OneDrive に移している場合は OneDrive 側のドキュメントになります）

- カードと評価の履歴は、すべてこの **1つのファイル** に入っています
- 正確な場所は、アプリの「データ」画面と、起動時の黒い画面に表示されます
- アプリ本体（このリポジトリ）とは別の場所にあるので、アプリを更新したりフォルダを消したりしてもデータは残ります
- 置き場所を変えたいときは、環境変数 `YAKUSHI_FLASH_DIR` にフォルダを指定して起動します

## バックアップ

次の3つの方法があります。

1. **自動バックアップ**：起動時に1日1回、`ドキュメント\yakushi-flash\backups\` に作られます（最新14個を残します）。JSON を取り込む直前にも自動で作られます
2. **手動バックアップ**：「データ」画面の「今すぐバックアップを作る」を押すと、同じ `backups` フォルダに日時つきのファイルができます
3. **ファイルをコピーする**：アプリを終了してから、`flashcards.db` を USB メモリやクラウドなど好きな場所にコピーします

> PCの故障に備えて、ときどき `backups` フォルダや `flashcards.db` を **PCの外**（USBメモリ・クラウドストレージなど）にもコピーしておくことをおすすめします。

## 復元（バックアップから戻す）

1. 黒い画面を閉じて、アプリを終了する
2. `ドキュメント\yakushi-flash\flashcards.db` の名前を変える（例：`flashcards_old.db`）。消さずに残しておくと安心です
3. 戻したいバックアップ（例：`backups\flashcards_20261120_093000_auto.db`）を `ドキュメント\yakushi-flash\` にコピーし、名前を **`flashcards.db`** に変える
4. `start.bat` で起動し直す

## JSON の書き出し・取り込み

- **書き出し**：「データ」画面 →「JSONファイルを書き出す」。全カードと評価の履歴が1つのファイルにまとまります
- **取り込み**：「データ」画面でファイルを選び、次のどちらかを選びます
  - **追加**：今のカードはそのまま、JSON のカードを新しいカードとして足す（学習状況と履歴も一緒に入ります）
  - **全置き換え**：今のカードと履歴をすべて消して、JSON の内容にする（別のPCへの引っ越しや、JSONからの復元に使います）
- どちらの場合も、取り込む前に自動でバックアップが作られます。JSON に1件でも不正なデータがあれば、何も変更せずに中止します

JSON の形式は `flashcards/io_json.py` の先頭に書いてあります。

## 自動テスト

`app` フォルダの `run_tests.bat` をダブルクリックするか、次のコマンドで実行します。

```bash
py -3 -m unittest discover -s tests -t . -v
```

| ファイル | 内容 |
|---|---|
| `tests/test_srs.py` | 間隔計算（○△✖、上限120日、午前2時の日付区切り） |
| `tests/test_store.py` | 出題順、再確認（1回だけ・間隔に影響しない・翌日には消える）、リセット、絞り込み・検索 |
| `tests/test_stats.py` | 今日の集計、連続日数、科目別・系統別の集計（周回数・定着率）、苦手リスト |
| `tests/test_io.py` | JSON の往復、追加・全置き換え、不正データでの中止、バックアップ |
| `tests/test_cloze_bulk.py` | 穴埋めの表示、一括追加の解析 |
| `tests/test_server.py` | サーバーを実際に起動して、API を通しで確認 |
| `tests/test_lan.py` | iPad から使うモード（パスコード、入力ミスでの一時停止、PC 以外からのアクセスの制限） |

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「Python 3.9 以上が見つかりませんでした」と出る | 上の「はじめての準備」でインストールしてください。インストール直後は、開いていたエクスプローラーをいったん閉じてから再度ダブルクリック |
| ブラウザが「接続できません」になる | 黒い画面が閉じていないか確認し、閉じていれば `start.bat` で起動し直してください |
| iPad で「接続できません」「応答がありません」になる | ① PC で `start_ipad.bat` から起動しているか ② iPad と PC が同じ Wi-Fi か ③ ファイアウォールで許可したか（上の「iPad から使う」）④ Windows のネットワークが「パブリック」になっていないか（「設定」→「ネットワークとインターネット」→ 使用中の Wi-Fi →「プライベート ネットワーク」）を確認してください |
| ポート 8765 がほかのソフトに使われている | 自動で 8766 以降の空いているポートを使います（黒い画面に表示されるアドレスを開いてください） |

## ファイル構成

```
app/
  start.bat              起動（ダブルクリック）
  start_ipad.bat         iPad からも使うモードで起動
  run_tests.bat          自動テストの実行
  server.py              ローカルサーバー（通常は PC 内だけ、start_ipad.bat では同じ Wi-Fi からも）
  flashcards/
    srs.py               間隔計算
    db.py                カード・評価履歴・学習セッション
    stats.py             集計
    cloze.py             穴埋め
    bulk.py              一括追加の解析
    io_json.py           JSON 書き出し・取り込み
    storage.py           データファイルの場所・バックアップ
    subjects.py          科目（9区分）
    lan.py               iPad から使うときのパスコード・接続の確認
  static/                画面（HTML / CSS / JavaScript）
  tests/                 自動テスト
```
